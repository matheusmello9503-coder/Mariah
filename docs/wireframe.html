Wireframe — Mariah Espaço Comercial

Etapa 2 do processo · tons de cinza, sem fotos reais, sem identidade visual — apenas blocos, hierarquia, ordem das seções e posição dos botões.

Como ler: blocos escuros = títulos · blocos médios = subtítulos/botões · blocos claros = texto de apoio · hachurado = foto (com nome do arquivo indicado quando relevante) · cápsulas = tags. Textos reais vêm de docs/copy.md só para facilitar a leitura da hierarquia — cor, fonte e espaçamento definitivos ficam para a etapa 3 (direção visual).
